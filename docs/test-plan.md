# 测试计划

## 第一层：本地自动化

- 亲属称谓与关系图：父母两侧、长幼、排行、从本人卡到所选人物的路径、信息缺失、多条路径和循环数据；验证祖辈、父母及其兄弟姐妹、本人及堂表兄弟姐妹分别同层，本人高亮，矛盾或断连节点不乱归层，搜索不破坏代际计算。
- 后端：记录隔离、跨录管理员越权、创建者移交须接收方确认且 72 小时过期、原创建者撤销、接收方拒绝及退出撤销、旧请求不能误生效；邀请过期／撤销／重复批准、陌生人申请前不能读取录内资料、移除后的访问；管理员修改已关联人物只影响本录、本人修改相同字段后旧覆盖失效；预录手机号不能自动给陌生账号访问权或把卡片资料回填该账号；城市坐标成对校验、取整及移除后清除，录内统一可见但不能跨录读取。
- 加入与资料关联：申请使用服务端保存的唯一账号资料，姓名、城市、生日月日和历法须完整；同窗录还须填写同班说明。拒绝旧客户端随申请提交 `claimPersonId`；同一邀请的申请被拒后不能再提交，管理员发新邀请后可重申。批准时明确选择已有资料或新建完整人物，同名不自动绑定；在已有家人的家人录新建时初始关系必填，关系冲突使整个审批回滚，选已有资料则展示旧卡与申请人姓名、生日、城市并保留原关系。审批和邀请消耗须原子完成，过期旧卡选择及预录手机号不一致须拒绝。已入录成员的认领申请不得由申请人自己审批；解除关联不得作用于同级、上级或本人。`join.mine` 仅返回本人申请及邀请失效状态；旧版无卡成员的关联流程、错误关联解除后的本录私人资料清理继续验证。
- 关系更正：`relation.preview` 不落库，新增／替换／删除展示边变化和受影响人物；同一人物对互斥边、亲子环及确定的代际矛盾被拒绝；关系建议须带结构化改动，采纳时关系、建议状态与审计一起提交，校验或并发冲突失败时建议保持待处理。资料和邀请文字建议可记录必填处理说明并标为 `handled`，但不能假称已自动修改；关系建议不能标为 `handled`。同一账号同一圈子的建议应限制为最多 5 条待审、滚动 24 小时最多 10 条，并发提交也不能突破限额。审核日志不暴露 OPENID，显示操作者、处理说明和改动摘要。
- 小程序码云函数：用模拟 SDK 验证仅本圈管理员能生成有效邀请的小程序码、`scene` 与微信分享同 token、二维码内容为 PNG；真实生成与扫描留待云端联调。
- 地图与城市：世界概览使用真实地理底图和聚合城市标记，点城市后进入微信原生详细地图并能返回；中国视图显示原生地图。逐级选择国家、省州和城市、搜索海外城市、未收录城市手动填写且标为待定位；列表人数与地图人数须能对账，未补齐生日或城市的旧卡明确列出。
- 生日事件：阳历、农历和闰月生日的下次公历日期，跨年、短月三十、阳历 2 月 29 日；仅本人所属记录和完整人物进入近期生日查询，前后端使用同一份公农历表，超出其年份范围时明确失败。
- 编译检查：前端 TypeScript、云函数构建、项目配置与文件引用。
- 可用性与重试：关键列表或关系读取失败时显示错误和重试，不将失败伪装成空数据；创建圈子与人物卡的响应丢失后使用同一请求 ID 重试，只产生一条记录；退出或被移出后旧的已批准申请不再提示能进圈；旧邀请可在管理入口重新查看并撤销。
- 照片安全与费用：客户端选图重编码，演示模式试选和替换预览不占持久空间，保存失败清理新文件；云函数剥离 JPEG 的 EXIF 等元数据；伪造 JPEG 和异常尺寸被拒绝；每账号 24 小时配额在并发上传下生效，失败后的配额退回只发生于云存储逐文件结果确认删除时。

## 第二层：本地交互

用演示数据走通建家人录和同窗录、按辈分显示整张关系网与本人高亮、点选人物后的称呼和关系路径、地图与列表人数对账、城市逐级选择与聚合。首页卡片人数须等于人物列表人数，无论人物是否使用过小程序。新增家人时，已有家人则必须选择一位已记录人物作关系对象、填亲子方向或兄弟姐妹长幼，人物与关系同时出现；未选关系或关系冲突时两者都不写入，只有首个人物例外。完成「管理员填写完整预录资料 → 受邀者填写唯一账号资料并查看申请状态 → 管理员核对已有卡旧资料后明确关联并批准」及「管理员选择创建新资料、指定初始关系并批准」两条路径。另核对旧空资料补录、同名提示、错误关联更正。管理页人物行可直接编辑资料与关系，普通编辑不出现移出或清空资料警告；访问与管理员区独立处理角色和移出。管理员改已关联人物后本录可见、其他录及对方账号资料不变；本人随后更新同字段，以新账号值覆盖旧更正。录入亲子关系时核对方向，预览并新增、替换、删除关系；成员提交结构化更正建议，管理员采纳后图和状态同步变化。手动填写一座目录外城市，确认列表保留且地图标为待定位；首页查看近期生日及全年生日页。此层使用模拟身份，属于页面和流程验证；模拟器通过后再做真机复核。

本轮还需在模拟器操作：关闭邀请页后重新进入并撤销旧邀请；分别断开关键数据请求，确认圈子、人物、编辑、管理、隐私页给出可读的重试状态；照片选取后能预览并保存，浅色提示文字在手机宽度上可辨认。

## 第三层：接入真实微信后

至少使用圈主、普通成员、未受邀者三个微信账号，在微信开发者工具和真机上验收：同一令牌的微信分享与小程序码扫码落地、一次性使用的并发审批、申请资料与旧卡绑定、跨圈数据隔离、圈内统一可见及移除成员后的即时拒绝、中国与世界地图、城市逐级选择、云存储图片权限、农历生日换算。记录每项测试账号、步骤、预期、实际与截图。云环境未就绪前，此层标记为待测，不能声称上线验证完成。

## 上线门槛

自动化测试通过；第一版验收场景在真机通过；误解绑、误删关系和移出成员的恢复方案已确定并验证，必要通知与特殊家庭关系的上线范围已定稿；小程序隐私指引、类目和备案按微信平台要求完成；云环境权限与费用告警已配置；上传开发版本并完成平台审核。
