# 亲缘图按可读性折叠家庭：设计与实现

日期：2026-10-05。适用范围：独立网页前端；后端人物、权限、亲属关系不变。

## 目标与触发

默认100%个人图保持原样，以本人为初始中心，游客不生成本人视角。不按人数强制切换。根据个人图姓名16px乘缩放比例得到屏幕字号：姓名小于11px且图超出当前容器时折叠；即使小家庭能放下，姓名小于8px也折叠。有家庭可合并时才切换，无可靠分组时保留个人图。

恢复阈值采用12px，避免在临界点反复切换。阈值均由当前容器尺寸和投影字号计算：例如百人手机视图70%仍是个人图，55%进入家庭图；反向放大时70%仍保持家庭图，85%恢复个人图。不是把这些百分比写成固定分界。

继续支持1%～160%，无85%等最低限制。家庭卡片使用独立的显示尺寸（显示缩放为个人比例的两倍），40%时姓名约14.4px。极小缩放用于看整体连接，提示放大看清姓名，不承诺1%还能阅读所有名字。

## 分组规则

1. 人物在显示分组中只归属一次，合计人数与原图一致。人物资料始终只有一份。
2. 明确且双方唯一的配偶形成一组；有自己配偶或子女的人不再并入父母的组。
3. 没有填写配偶但明确共同为某些人的父母，且双方没有其他配偶/共同育儿对象时，可显示“甲、乙与子女”；不会因此新增或推定婚姻。
4. 无自己家庭的人，仅在所记录的父母与该组的全部家长准确对应时并入。例如仅记录爸爸，而爸爸有配偶，不能把配偶自动视为妈妈；该子女保留独立卡片和真实连接。
5. 单亲可与其明确记录的子女合并。只有兄弟姐妹关系不猜父母，不凭年龄判断是否成家。
6. 多配偶、多组共同育儿对象、矛盾关系保守分开；未记录关系的人独立保留。当前模型没有前配偶状态，不通过猜测处理再婚。
7. 即使某位父母/配偶不在原图160人的显示范围内，也保留其关系作为合并约束，避免被截断后误当唯一父母或配偶。

## 家庭之间的联系

组内关系收起，跨组的亲子、配偶、兄弟姐妹连线保留；同类重复组间连线合并。父母家庭与子女自己家庭通过真实亲子线连接。

布局从子辈向上排列，让父母对齐其子女家庭的中心，并为相邻卡片保留间距；不把每一代机械居中在整个家族的正上方，避免手机上父母卡片远离自己的分支。

点击家庭卡片，以可关闭的成员窗口展开这一家，其他卡片仍保持折叠。窗口提供成员头像/姓名和跨组父母、子女入口，成员资料沿用现有只读/本人/管理员权限。点击跨组家人恢复个人图并定位该人。关闭窗口保留缩放和滚动位置。

卡片人数是该显示组实际包含的人物数；成家后单独显示的子女通过连线及窗口入口访问，不重复计数。标题从家长/配偶姓名生成，不按姓氏或男方决定归属。

## 定位与手机交互

- 切换布局以视口中心附近的人为锚点，切换到他的家庭卡片或恢复到对应人物，禁止因为边界尺寸变化重置到100%。
- 搜索定位、找到我、重置恢复100%个人图；搜索和备注沿用当前角色已获准的数据。
- 自己所在的家庭卡片高亮并显示“我在这里”，游客无此标记。
- 滚动定位在React布局阶段完成，避免新旧坐标短暂错位。展开图时将图滚动到固定返回栏下方，避免扩大的画布落在屏幕底部。
- 家庭窗口关闭按钮沿用吸顶与键盘焦点管理；头像失败沿用文字回退。

## 验收边界

自动化覆盖小家庭、已成家的兄弟姐妹、双方父母、单亲、继亲/半同胞、共同父母但无婚姻记录、多配偶、缺失记录、160人截断边界、关系矛盾、游客、四代百人去重及连线、卡片不重叠、折叠缓冲阈值。

浏览器使用本地虚构百人家庭和手机尺寸模拟，验证缩放、家庭展开、资料、搜索、自己定位与关闭返回；不等同于iPhone/Android真机触控验收。原图最多显示160人的限制和额外名单入口保留。
