# 人间星图

记录家人的关系、近况、所在城市与生日。当前为家庭专用的 **React 网页前端 + Node.js API 后端**，手机和电脑均可使用。

## 本地启动

需要 Node.js 22.16 或以上版本。

```powershell
npm ci
npm run seed:demo
npm run dev
```

打开 <http://localhost:5173>。后端运行在 `127.0.0.1:3001`，前端通过 `/api` 代理调用后端。示例数据存入 SQLite，刷新或重启不会丢失。

显式执行 `seed:demo` 才会初始化演示账号：

- 管理员：`13800000000`，密码：`LocalDemo2026!`
- 普通成员：`13800000001`，密码：`LocalDemo2026!`

这些是本地测试资料；生产环境不运行种子脚本。不需要示例时，跳过 `seed:demo`，在服务器终端执行 `npm run setup:family`，交互创建首个管理员和家人录。网页不提供公开注册和另建家人录；亲戚由管理员邀请加入。

## 开发与构建

```powershell
npm run dev:web       # 仅启动网页前端
npm run dev:api       # 仅启动 API
npm run build         # 编译网页与业务后端
npm test              # 原业务回归、网页类型检查、HTTP 与持久化测试
npm start             # 运行已构建的后端
```

前端构建产物为 `frontend/dist/`，可以托管在静态服务器上。后端由 `server/index.cjs` 启动，复用 `backend/dist/` 的业务服务。前后端可以分别发布；推荐由统一域名将 `/api` 转发到后端，简化 Cookie 和跨域设置。

## 部署

已提供两个独立 Docker 镜像与 `compose.yaml`。将 `deploy.env.example` 复制为 `.env`，填写自己的域名后执行：

```powershell
docker compose up -d --build
docker compose exec api node server/setup.cjs
```

前端容器负责静态网页、HTTPS 和 `/api` 转发；后端容器负责业务接口、账户会话、SQLite 数据库和私有照片。数据使用持久卷，更新镜像不会清空资料。

详见 [部署、备份和独立发布说明](docs/web-deployment.md)。本地机器没有 Docker 时仍可直接使用 Node.js 运行。

## 功能

- 家人录：亲缘图、家人簿、天南海北；切换视图时关闭人物详情，点击家人后查看。
- 一份个人资料，支持照片、联系方式、城市、职业、阳历／农历生日。
- 按辈分排列的亲缘图、本人高亮、亲属称呼与自己的备注。
- 中国／世界地图、中国省界与城市地名、同城成员列表、逐级选择城市。
- 近期 30 天生日提醒，农历生日自动换算；账号首页排除本人，游客展示全部家人。
- 管理员从“我的”进入管理：添加成员、修改资料与关系、审批加入、管理邀请与成员权限。
- 一次性短期邀请链接／二维码，尚不清楚的亲属关系可以以后补充。
- 受邀注册、管理员审核后加入；本网站只服务已初始化的家庭，不开放自助创建。
- 管理员添加家人时填写本人登录手机号；同号码受邀注册可直接带入已有资料，审批后沿用原人物和亲属关系，本人可继续修改。
- 游客输入家庭名称即可只读浏览家人资料、近期生日、亲缘图和地图；无需注册账号。
- 可选择在自己的手机上记住登录 90 天，查看和退出已登录设备。

## 登录与当前边界

游客选择“游客看看”，输入家庭名称即可浏览。按产品所有者明确选择，游客可查看家人照片、姓名、城市、生日、手机号、微信和近况；家庭名称不是密码，知道或猜中名称的人也能查看这些资料。游客没有编辑、备注、上传、邀请、审批或管理权限，其他账号的私人备注不对游客提供。

维护资料采用 **手机号 + 密码** 登录：普通成员维护自己的资料和私人备注；管理员从专门管理页维护家庭成员与关系。添加家人须填写有效手机号，无需代设密码。本人打开邀请，用相同手机号注册后，确认“这是我，使用这份资料”即可带入姓名、城市、生日等信息；管理员确认后使用原人物和关系，不重复建人。手机号尚未短信验证，因此仍需管理员核对身份；历史资料设置过独立核对号码的，继续执行原验证规则。短信找回密码尚未接入，已登录用户可修改密码。

后端从 HttpOnly Cookie 会话中确定账号，不信任前端提交的用户 ID 或管理员角色。私人照片每次请求都重新检查访问权限。SQLite 版本适合单个 API 实例部署；多实例部署前须更换支持共享事务的数据库适配器。

账号注册必须携带管理员生成的有效家庭邀请，一份邀请最多注册一个账号；注册本身不授予家庭成员资格，完善资料并经管理员批准后才能以成员身份进入。登录除核对密码，还要求有效家庭成员资格或有效的受邀加入流程。无资格的历史账号直接拒绝登录；打开新的有效邀请后，可用原手机号和密码继续加入，无需重复注册。受邀待完善／待审核账号显示加入进度；邀请过期、撤销、申请被拒或移出后不能靠旧登录状态继续使用成员功能。游客浏览独立于账号登录，不创建账号或成员。创建新家人录的 Web API 已关闭，初次初始化只允许通过服务器本地命令完成。

普通登录有效期 7 天；选择“这是我的手机，记住登录”后有效期为固定 90 天，到期重新登录。关闭浏览器不会立即退出，但清除网站数据、更换浏览器或使用微信内置浏览器可能需要重新登录。“我的”提供已登录设备管理；修改密码会退出其他设备，变更管理员等重要操作要求近期密码确认。

网页版仅支持家庭记录。同窗创建、邀请、资料和提醒已移出当前产品；旧版本数据库中的同窗记录保留在存储中，但网页与 API 不再提供访问。家人资料和关系不受影响，演示初始化也只创建家庭资料。

地图默认使用随网站一起部署的 Natural Earth 矢量底图和本地城市目录，无需地图密钥或第三方瓦片服务。默认中国，放大可查看省界及基础城市名称，选择家人所在城市可查看周边城市；不提供街道导航或市辖边界。数据来源、许可及更新方式见 [网页底图说明](docs/web-basemap-data.md)。

## 目录

- `frontend/`：React + TypeScript + Vite 网页前端。
- `server/`：HTTP、账户、SQLite 适配器、私有照片及集成测试。
- `backend/`：复用的业务服务、权限规则与业务测试。
- `packages/`：亲属称呼、公农历换算等共用逻辑。
- `deploy/`、`compose.yaml`：前后端独立镜像和组合部署。
- `miniprogram/`、`cloudfunctions/`：保留的小程序代码与历史回归测试，不是网页版的运行依赖。

原小程序说明保存在 [历史说明](docs/miniprogram-history.md)。网页版测试证据见 [迁移与验收记录](docs/web-migration-test-report.md)。
