# 测试计划

## 第一层：本地自动化

- 亲属称谓：父母两侧、长幼、排行、切换视角、信息缺失、多条路径和循环数据。
- 后端：圈子隔离、跨圈管理员越权、邀请过期/撤销/重复批准、陌生人申请前的可见范围、移除后的访问、手机号/微信号隐藏、长辈授权撤销。
- 编译检查：前端 TypeScript、云函数构建、项目配置与文件引用。

## 第二层：本地交互

用演示数据走通建家庭圈和同学圈、切换关系视角、录入人物、地图与列表一致、城市聚合、发邀请与审核。此层使用模拟身份，属于页面和流程验证。

## 第三层：接入真实微信后

至少使用圈主、普通成员、未受邀者三个微信账号，在微信开发者工具和真机上验收：微信分享与扫码邀请、一次性使用的并发审批、跨圈数据隔离、本人资料可见范围、移除成员后的即时拒绝、中国与世界地图、云存储图片权限。记录每项测试账号、步骤、预期、实际与截图。账号和云环境未就绪前，此层标记为待测，不能声称上线验证完成。

## 上线门槛

自动化测试通过；第一版验收场景在真机通过；小程序隐私指引、类目和备案按微信平台要求完成；云环境权限与费用告警已配置；上传开发版本并完成平台审核。
