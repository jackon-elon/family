## 待验证与当前限制

- **微信运行环境**：已从腾讯发布的 2.02.2609231 Windows 安装包启动开发者工具，CLI 可以连接；`open --project D:\小程序` 在导入时因 `touristappid` 报“不存在此 AppID”。`open-other` 只打开普通代码窗口，未编译小程序。取得测试号或已有 AppID 后，还需按[前端设计](frontend-design.md)逐页操作模拟器。
- **真实云环境**：尚无 AppID 和 CloudBase 环境 ID。云函数的真实 `OPENID`、数据库事务、安全规则、照片存储和短期链接、跨账号权限，需要接入后实测。`api` 必须只接受已绑定小程序的事件调用；不可混用 HTTP、Web 或其他触发来源。
- **二维码**：本地页面明确标注为不可扫码的预留位。邀请码已压到微信小程序码 `scene` 可承载的 32 字符；小程序码生成、扫码直达与微信分享要在有 AppID 后联调。
- **地图**：当前是城市分布示意图，内置常见城市坐标。未收录城市可手填并留在列表，但暂不落地图点；接入更完整的城市地理编码后再做真实底图验收。
- **页面范围**：资料导出、重复人物卡合并和常用叫法持久化尚未接入前端；人物照片列表目前只给首批 20 张请求短期链接。以上不影响本地核心流程，但在正式上线前需按需求文档确认取舍并验收。

上线判断应以[测试计划](test-plan.md)的真实账号和真机场景为准，本报告只记录已经执行的本地检查。
