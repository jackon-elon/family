# 微信小程序前端设计与本地演示

## 启动

小程序源代码位于 `miniprogram/`，是独立的原生微信小程序项目。用微信开发者工具导入这个目录即可看到本地演示，不需要 AppID、云环境或 npm 安装。`project.config.json` 使用 `touristappid` 和微信内置 TypeScript 编译插件。演示模式默认开启，数据保存在当前开发者工具或设备的本地存储；首页可恢复初始样例。

正式连接云端时，先将 `miniprogram/project.config.json` 的 AppID 换成自己的小程序 AppID，并在 `miniprogram/config.ts` 填写 CloudBase 环境 ID，部署名为 `api` 的云函数。只有环境 ID 非空且 `wx.cloud.callFunction` 可用时，首页才允许切换云端模式。所有页面通过 `miniprogram/services/api.ts` 的 `invoke({action,payload})` 访问数据，成功返回 `{ok:true,data}`，失败返回 `{ok:false,error:{code,message}}`。云端权限必须由后端检查，页面上的按钮隐藏只服务于用户体验。

## 页面与操作

| 页面 | 用途 |
| --- | --- |
| 我的圈子 | 家庭圈和同学圈分组浏览、建圈入口、演示/云端状态 |
| 新建圈子 | 选择圈类型、自己记录或邀请共建；同学圈必填学校、届别、班级 |
| 圈子首页 | 家庭关系网/列表/地图，同学列表/地图；搜索、筛选、视角切换 |
| 人物资料 | 称呼及解释路径、公开资料、联系方式、认领/更正入口 |
| 编辑人物卡 | 本人编辑资料和照片；管理员为未认领卡只填最少资料；受托人只编辑授权字段 |
| 管理圈子 | 审核加入与认领、处理更正建议、成员移除、家庭关系录入和删除 |
| 邀请加入 | 资料分享预览、生成 72 小时一次性邀请、分享/口令、撤销 |
| 申请加入 | 只显示有限圈信息，填写身份说明并等待管理员审核 |
| 资料可见范围 | 照片、城市、学校、行业、职业、状态、近况、电话和微信号逐项设置；长辈代维护授权与撤销 |

家庭圈视角和称呼由共享 `packages/kinship` 引擎计算。构建/检查时 `scripts/sync-kinship.mjs` 将同一份源代码复制到 `miniprogram/vendor/kinship.ts`，前端适配器把后端 `parent/spouse/sibling` 边转换成引擎输入。资料不完整时展示引擎给出的路径和缺项，不猜称呼。列表、地图和搜索都严格使用当前 `circleId` 获得的人物数组，不跨圈混合。

地图页先给一屏中国/世界城市分布示意图，城市点按人数聚合，点击后展示该城可见人物。图形是便于手机总览的示意底图，不是精确行政区地图。人物资料允许自由填写国家/地区、省/州、城市；目前已配置常见城市的城市级坐标。未知城市仍出现在列表中，并计入“暂未定位”提示，不强行放置错误地图点。地图不采集实时位置。

照片在演示模式保存到本机文件路径。云端模式先保存人物卡，再把小于 1 MiB 的 JPG 以 base64 交给受鉴权的 `photo.upload` 云函数；不从客户端直接写云存储。可见人物的照片使用 `photo.url` 获取短期链接，最多为当前页面首批 20 人请求，未获取到时使用文字头像。

微信分享按钮在真实小程序身份下分享一次性邀请。页面中的二维码是**明确标注的预留位，当前不可扫码**；演示模式可用“预览受邀者申请页面”模拟申请与审核。正式二维码需要服务端生成与分享卡片同一 token 的小程序码，并在上线前完成微信能力联调。

## 自动检查

在项目根目录运行：

```text
npm run typecheck:frontend
node --test miniprogram/tests/*.test.cjs
```

前端测试覆盖城市聚合与未知城市、两类圈子数据隔离、未认领和他人隐私字段过滤、共享称呼引擎视角切换、一次性邀请，以及同学圈班级字段约束。根目录的 `npm test` 还会运行后端、称呼引擎与项目文件检查。

## 开发者工具手工验收路径

1. 导入 `miniprogram/`，从首页进入家庭圈。点伯父人物卡，确认称呼与“我 → 爸爸 → 爸爸的哥哥”路径；切换为爸爸视角，称呼应重新计算。
2. 家庭圈切换中国/世界地图。世界总览能看到海外城市点，点城市可打开该城人物；切回列表仍在同一个家庭圈。
3. 进入同学圈，按城市、状态、行业筛选；隐藏城市的人仍可在列表中找到，但不出现在城市点。
4. 编辑自己的城市、职业和联系方式，进入可见范围页分别关闭或开启展示；手机和微信号初始仅本人可见。
5. 管理页生成邀请，预览申请页提交说明，回到管理页批准。再次用同一份邀请申请或批准另一人，应得到已使用提示。
6. 新建自己记录的圈子，首次邀请时先确认历史资料可见范围，随后升级为邀请共建。
7. 作为管理员增加一张未认领卡，建立家庭关系；尝试删除关联卡时应先看到关系影响提示。

目前未在此仓库内完成真实 AppID、云环境和微信分享/扫码联调。上线前需用真实账号在微信开发者工具与真机执行上述流程，并核对云函数部署、照片短期链接和权限规则。
